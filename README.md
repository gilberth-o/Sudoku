# Stillmind Sudoku

A calm, responsive Sudoku homepage and playable daily puzzle built with plain
HTML, CSS, and JavaScript. Choose a square and enter numbers with the number
pad or keyboard. Use **Check puzzle** to see your progress, or **Clear entries**
to start again.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site. The project
uses `index.html` at the repository root, so no build command or output
directory is needed.
