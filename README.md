# Shinobi Sudoku

A Naruto-inspired, responsive Sudoku site built with plain HTML, CSS, and
JavaScript. The landing page is `index.html`, the playable daily puzzle lives
on its own page at `puzzle.html`, and local stats are shown at `progress.html`.

On the puzzle page, choose a square and enter numbers with the number pad or
keyboard. Use **Check puzzle** to see your progress, or **Reset mission** to
start again. Completed puzzles update your solved count, best time, and
consecutive-day streak. Progress is stored in this browser on this device.

## Run locally

Open `index.html` in a browser and select **Today's mission** to play, or use
**Progress** to view your stats. No build step or dependencies are required.

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site. The project
uses `index.html` at the repository root, so no build command or output
directory is needed.
